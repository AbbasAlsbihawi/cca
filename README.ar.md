# cca

تتيح لك cca تشغيل عدة حسابات Claude على جهاز Mac واحد، مثل حساب شخصي وحساب للعمل وحساب لعميل، في Claude Code داخل الطرفية وفي تطبيق Claude لسطح المكتب. لا تحتاج إلى تسجيل الخروج للتبديل بينها.

cca أداة غير رسمية، وليست تابعة لشركة Anthropic.

## المتطلبات

- macOS وzsh
- أداة سطر الأوامر Claude Code (`claude`)
- تطبيق Claude لسطح المكتب، للجزء الخاص به فقط
- jq (اختياري): ينسخ خوادم MCP إلى الحسابات الجديدة

## التثبيت

```sh
git clone https://github.com/AbbasAlsbihawi/cca.git && cd cca && ./install.sh
```

ثم افتح طرفية جديدة.

لإلغاء التثبيت، شغّل `./uninstall.sh`. هذا الأمر يحتفظ ببيانات حساباتك. لحذف البيانات أيضاً:

```sh
rm -rf ~/.claude-accounts
```

## البداية السريعة

1. سمِّ تسجيل الدخول الحالي أولاً. افعل ذلك قبل ربط أي مجلد.

   ```sh
   echo work > ~/.claude-accounts/default-name
   ```

2. أضف حساباً ثانياً. يفتح هذا الأمر المتصفح لتسجيل الدخول.

   ```sh
   cca add personal --email you@example.com
   ```

   إذا كان المتصفح مسجلاً الدخول إلى حساب Claude آخر، فبدّل الحساب فيه، أو استخدم نافذة خاصة.

3. في مجلد مشروع، اربط المجلد بحساب.

   ```sh
   cd ~/projects/client-x
   cca bind personal
   ```

4. استخدم حساباً في طرفية واحدة، أو لتشغيل واحد.

   ```sh
   cca use personal     # في هذه الطرفية
   cca use -            # إيقاف الاستخدام في هذه الطرفية
   cca run personal     # تشغيل واحد فقط
   ```

5. اعرف الحساب المستخدم هنا.

   ```sh
   cca
   ```

## الأوامر

| الأمر | ماذا يفعل |
|---|---|
| `cca` | يعرض الحساب المستخدم هنا، وكل الحسابات والمجلدات المربوطة |
| `cca add <name> [opts]` | ينشئ حساباً ويسجل الدخول (الخيارات: `--email you@x.com`، `--sso`) |
| `cca login <name> [opts]` | يسجل الدخول من جديد (عند انتهاء الجلسة، أو عند اختيار الحساب الخطأ) |
| `cca use <name>` | يستخدم حساباً في هذه الطرفية (`cca use -` للإيقاف) |
| `cca bind <name> [folder]` | يستخدم حساباً دائماً في مجلد وفي مجلداته الفرعية |
| `cca unbind [folder]` | يزيل ربط مجلد |
| `cca run <name> [args]` | يشغّل claude مرة واحدة بحساب |
| `cca list` | يعرض الحسابات مع بريدها الإلكتروني |
| `cca app <name> [color]` | ينشئ تطبيق 'Claude <Name>' في ~/Applications لذلك الحساب، بأيقونة ملونة |
| `cca open <name>` | يفتح تطبيق Claude لحساب (أو يعرضه في المقدمة إن كان مفتوحاً) |
| `cca remove <name>` | يسجّل خروج الحساب، وينقل مجلداته ومشغِّله إلى سلة المهملات |
| `cca import <name> [-n]` | ينسخ جلسات Code القديمة للحساب من تطبيق Claude الرئيسي (`-n`: تجربة بدون نسخ) |

## الحساب الذي يستخدمه `claude`

يُعمل بأول تطابق:

1. `cca use <name>` في هذه الطرفية
2. مجلد مربوط بـ `cca bind <name>` (هذا المجلد أو مجلد أب له)
3. الحساب الافتراضي (`~/.claude`)

داخل جلسة Claude Code، يحتفظ `claude` بحساب تلك الجلسة.

يطبع `claude` سطراً باهتاً، `claude account: ...`، قبل أن يبدأ. اضبط `CCA_QUIET=1` لإخفائه.

## تطبيق سطح المكتب

```sh
cca app personal
```

يُنشئ هذا الأمر `~/Applications/Claude Personal.app`. اسحبه إلى Dock.

أعطه لوناً للتمييز بين الحسابات: `cca app personal purple`. الألوان: red وorange وyellow وgreen وteal وblue وpurple وpink وgray. إذا أعدت تشغيل `cca app personal` لاحقاً فسيحتفظ باللون. اللون غير المعروف خطأ ولا يغيّر شيئاً. إذا تعذّر تلوين الأيقونة، يظهر تحذير وتبقى الأيقونة العادية.

عند النقر على المشغِّل، تُفتح نسخة تطبيق Claude الخاصة بذلك الحساب، أو تُعرض في المقدمة إن كانت مفتوحة. لا يفتح نسخة ثانية على البيانات نفسها أبداً.

أول تسجيل دخول:

1. أغلق كل نوافذ Claude (Cmd+Q).
2. افتح النافذة الجديدة فقط، وسجّل الدخول.
3. أعد فتح الباقي.

يعود رابط تسجيل الدخول عبر `claude://`. إذا كانت نسختان مفتوحتين، فقد يصل الرابط إلى النسخة الخطأ.

يطلب macOS مرة واحدة إذناً للسماح للمشغِّل بالتحكم في System Events. اسمح بذلك. يستخدمه المشغِّل لعرض النافذة الصحيحة في المقدمة.

لكل نسخة سطح مكتب مجلد بيانات خاص بها، وهو `~/.claude-accounts/desktop/<name>`. وتبويب Code فيها يستخدم مجلد إعدادات ذلك الحساب.

## كيف يعمل

لكل حساب مجلد إعدادات خاص، يُحدَّد بالمتغير `CLAUDE_CONFIG_DIR`. لذلك يملك كل حساب تسجيل دخول خاصاً به، وإدخالاً خاصاً به في سلسلة المفاتيح (Keychain). الحساب الافتراضي هو `~/.claude`.

هذه الملفات مشتركة مع `~/.claude` عبر روابط رمزية (symlinks):

- `settings.json`، و`CLAUDE.md`، والمهارات (skills)، والإضافات (plugins)
- `agents`، و`commands`، و`output-styles`، و`keybindings.json`، إن وُجدت

وهذه الملفات منفصلة لكل حساب:

- سجل المحادثات
- الذاكرة

## الملفات

- `~/.claude-accounts/cca.zsh`: السكربت
- `~/.claude-accounts/default-name`: اسم الحساب الافتراضي
- `~/.claude-accounts/bindings`: ربط المجلدات
- `~/.claude-accounts/profiles/<name>/`: مجلد إعدادات كل حساب
- `~/.claude-accounts/desktop/<name>/`: مجلد بيانات كل نسخة سطح مكتب
- `~/Applications/Claude <Name>.app`: مشغِّلات سطح المكتب
- سطر واحد في `~/.zshrc` يحمّل `cca.zsh`

## نقل المحادثات القديمة إلى نسخة الحساب

إذا استخدمت تطبيق Claude الرئيسي بحساب ما قبل أن تنشئ له نسخة خاصة، فجلسات تبويب Code لذلك الحساب ما زالت في التطبيق الرئيسي. انسخها هكذا:

```sh
cca import personal --dry-run   # يعرض ما سيُنسخ فقط
cca import personal
```

أغلق نسخة ذلك الحساب أولاً. يَنسخ الأمر قائمة الجلسات وسجلات الرسائل التي تشير إليها، ولا يكتب فوق أي ملف ولا يحذف شيئاً، ويبقى كل شيء في التطبيق الرئيسي كما هو. يتعرّف الأمر على الحساب من تسجيل دخوله في الطرفية (`cca login`)، أو من الحساب الوحيد الذي سجّلت به نسخته الدخول؛ وإلا فمرّر `--account <uuid>`. أما محادثات تبويب Chat فهي محفوظة على خوادم Anthropic، وتظهر تلقائياً بعد تسجيل الدخول بالحساب نفسه.

## حذف حساب

```sh
cca remove personal
```

يسجّل هذا الأمر خروج الحساب، ويزيل ربط مجلداته، وينقل مجلد إعداداته وبيانات نسخة سطح المكتب والمشغِّل إلى سلة المهملات (استخدم Put Back للتراجع). أغلق تطبيق Claude الخاص بذلك الحساب أولاً. في الحساب الافتراضي يُزال تسجيل الدخول والمشغِّل فقط، ويبقى `~/.claude`.

## حل المشكلات

- `command not found: cca`: افتح طرفية جديدة، أو شغّل `source ~/.zshrc`.
- بعد تحديث cca، تأخذ الطرفيات المفتوحة النسخة الجديدة تلقائياً عند أول أمر `cca`.
- نسخة سطح المكتب تعرض الحساب الخطأ: أغلق كل نسخ Claude، وافتح تلك فقط، ثم سجّل الخروج، ثم سجّل الدخول.
- تسجيل الدخول يختار حساب Google الخطأ: اكتب البريد الإلكتروني واستخدم "Continue with email" بدلاً من "Continue with Google".
- الطرفية تستخدم الحساب الخطأ: شغّل `cca login <name>`.

## إخلاء المسؤولية

يعتمد جزء سطح المكتب على سلوك غير موثّق في التطبيق. قد يتوقف عن العمل بعد تحديث التطبيق.

استخدم cca للفصل بين حساباتك الخاصة. اتبع سياسات مؤسستك. لا تستخدمه للالتفاف على حدود الاستخدام.
